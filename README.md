# BB84 Quantum Key Distribution Simulation

A implementation of the **BB84 quantum key distribution protocol** using Python, Qiskit, and Qiskit Aer.

### Current Features
- Random bit and basis generation for Alice, Bob, and Eve.
- Quantum state preparation and measurement.
- Basic intercept-resend eavesdropping simulation.
- Key sifting and QBER estimation.
- Configurable depolarizing noise model.

### Future Plans
- Implement error correction and privacy amplification.
- Analyze QBER under different noise levels and eavesdropping strategies.
- Improve the simulation and key-generation workflow.

**Status:** Work in progress — currently a basic simulation; secure key distillation and complete protocol validation are yet to be implemented.
